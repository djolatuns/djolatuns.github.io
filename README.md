# DJ Olatuns Digital Platforms

This repository contains two independent, mobile-first progressive web experiences:

- **DJ Olatuns App** — music discovery, mixtape links, community preview, booking enquiry and DJ learning information.
- **OLATUNS WORLD** — an editorial hub for news, entertainment, events, opportunities, technology and lifestyle.

## URLs
- Main app: https://djolatuns.github.io/
- OLATUNS WORLD: https://djolatuns.github.io/olatuns-world/

## Important implementation notes
The project is a static GitHub Pages front end. Community posts are stored locally in the visitor's browser. The booking form prepares an email draft. Messaging, account authentication, shared publishing, real-time notifications and server-side administration require a secure backend and are not represented as live services in this static starter.

Replace sample editorial cards with verified posts before treating them as current news. Add official Audiomack release URLs when available.
